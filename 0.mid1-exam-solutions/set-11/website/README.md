# DevOps Tools Quick Reference

| Tool | Purpose | Common command | Website |
| --- | --- | --- | --- |
| Git | Tracks source-code changes | `git status` | [git-scm.com](https://git-scm.com/) |
| Docker | Packages software into containers | `docker ps` | [docker.com](https://www.docker.com/) |
| Jenkins | Automates build, test, and delivery | `jenkins` | [jenkins.io](https://www.jenkins.io/) |
| Kubernetes | Orchestrates containers | `kubectl get pods` | [kubernetes.io](https://kubernetes.io/) |
| AWS | Cloud computing platform | `aws --version` | [aws.amazon.com](https://aws.amazon.com/) |

## Git

Git is a distributed version-control system. It tracks file history and supports branching and merging.

```bash
git status
```

## Docker

Docker packages an application and its dependencies into a portable container.

```bash
docker ps
```

## Jenkins

Jenkins automates CI/CD tasks such as building, testing, and deploying software.

```text
Build Now -> Console Output
```

## Kubernetes

Kubernetes manages deployed container applications across machines.

```bash
kubectl get pods
```

## AWS

AWS provides cloud services such as servers, storage, databases, and networking.

```bash
aws --version
```
